# Dearby

모집 중 활동을 발견하고, 공개 범위를 고른 명함을 활동 맥락과 함께 교환·보관하는 iOS·Android 서비스입니다.

2026-09-27 확정 Seed에 따라 네이티브 앱과 서버를 구현 중입니다. 이전 Next.js 실행 코드는 제거했습니다. 전체 서비스나 운영 연동이 완료된 상태는 아닙니다.

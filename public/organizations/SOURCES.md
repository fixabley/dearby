# 기업 아바타 로고 출처

확인일: 2026-09-24. 기업 공식 홈페이지의 기업 식별 로고를 로컬 보관한다. 행사 포스터·생성한 텍스트 로고가 아니다. 원본 도형과 비율을 유지하고 흰 배경에서 표시한다. 인접 조직명이 있으므로 UI 이미지는 장식 이미지로 처리한다. 공식 로고가 없는 커뮤니티/GDG는 기존 이니셜이며 Google 등 다른 회사 로고로 대체하지 않는다.

우아한형제들 홈페이지는 확인 당시 브라우저에서 잘못된 요청 화면으로 이동했다. 최초 HTML이 참조하는 공식 CDN의 header-logo 컴포넌트와 한국어 로고 모듈을 확인해 path/clipPath/viewBox를 그대로 SVG로 옮겼다. 다른 inline SVG도 도형을 다시 그리지 않고 공식 마크업을 저장했다. 이 기록은 상표/이미지 사용권 허용을 주장하지 않는다. 각 기업에 권리가 있으며 배포 시 사용 조건은 별도로 확인해야 한다.

## KSUG 조직 로고 추가 — 2026-09-24

- 공식 페이지: https://ksug.org/ (문서 제목 Korea Spring User Group | KSUG, 본문 한국 스프링 사용자 모임 소개)
- 원본: https://ksug.org/assets/images/logo.png → 로컬 `ksug.png`
- 홈페이지 상단에서 사용하는 KSUG / KOREA SPRING USER GROUP 조직 식별 로고를 원본 그대로 저장했다. Spring Camp를 주최하는 `org-ksug`에 적용하며 Spring 프레임워크·Pivotal 로고나 행사 포스터가 아니다.
- 기업8개 외에 공식 로고를 확인한 커뮤니티 KSUG만 추가했다. 다른 커뮤니티 이니셜은 유지한다. 원본은 가로로 긴 워드마크라 작은 아바타에서는 하단 영문이 작으며 인접 조직명이 식별을 보완한다. 확인일 2026-09-24, 사용권 허용을 별도로 확인했다는 의미는 아니다.

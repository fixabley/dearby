# 겹치는 시간 — 시안 A 적용

2026-09-29 사용자가 새로 제공한 이미지 폴더에서 `calendar-30min-a.png`를 명시적으로 선택했다. 정본은 [원본 A](../../../../../docs/design/approved/calendar-overlap-a.png), 원본 PNG는 수정 없이 복사했다. 이번 구현은 현재 사용 중인 iOS 시뮬레이터이며 Android는 변경하지 않았다.

- 날짜·정확한 겹침 분량·두 열 시간표·주황색 겹침 띠·진행 순번·확인 버튼을 적용했다. 활동/바쁜 시간의 원래 구간과 교집합을 각각 표시한다.
- 시간축은 겹침 30분 전부터 최소 2시간, 또는 겹침 끝 30분 뒤까지다. 범위 밖 일정은 계속 표시로 안내한다. 24시간 표기와 활동 시간대를 사용하며 날짜를 넘기는 구간은 날짜도 표시한다.
- EventKit의 실제 결과를 사용한다. 개인 일정 제목을 가져오거나 저장하지 않으므로 시안의 회의 제목은 ‘바쁜 시간’으로 표시한다. 일정 수정/서버 전송은 없다.
- 비교할 캘린더 선택은 유지하며 결과 아래에서 다시 펼칠 수 있다. 권한 거부·시각 미확인·실패·겹침 없음은 별도 상태로 유지한다. 결과 이동은 맨 위에서 시작한다.
- 큰 글자에서는 두 열 그림을 세로 시간 목록으로 바꾸며 고정 확인 버튼을 유지한다. VoiceOver에는 그림의 활동/바쁜 시간/겹침 전체 구간을 하나의 설명으로 제공한다.

## 검증

- 첫 실행: 캘린더 단위6통과/3조건부 skip(권한거부 전용/전용 테스트 기기/일회성 시딩), UI3통과. 실제 임시 일정의 30분 겹침2건, 다음/이전/완료, 상세→캘린더→신청 흐름 확인.
- 24시간 표기 수정 후: 단위1/UI1통과. 큰 글자 UI는 화면 밖 버튼을 XCTest가 hittable로 반환하여 진입 실패. 버튼이 고정 신청 영역 위에 완전히 보이도록 스크롤 조건을 보강했고, 결과 전환 시 스크롤 위치를 초기화했다.
- 최종 재실행: 일반 크기 결과2건 이동/이전/완료와 최대 접근성 크기 진입/결과/고정 확인 버튼 UI2건 모두 통과(`/tmp/dearby-calendar-a-verified.xcresult`). 실제 캡처 first/second/large.png를 시각 확인했다.
- 구조16통과. SwiftLint65파일0위반. 빌드·설치·실행 성공.
- Ponytail review: 추가 패키지·별도 렌더링 엔진 없이 SwiftUI 도형과 기존 상태/버튼을 사용한다. 별도 타임라인 View는 좌표 계산/표시 책임만 가진다. Lean already. Ship.

시안의 전화기 프레임·질감·샘플 날짜·일정 이름은 재현 대상이 아니다. 시트 헤더/닫기는 OS 기본 내비게이션 외형을 유지한다. 실기기, Android, 작은 기기, VoiceOver 음성 탐색 전체는 이번에 실행하지 않았다.

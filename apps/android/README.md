# Android 클라이언트

Kotlin 네이티브 앱을 위한 디렉터리입니다. 앱 프로젝트는 아직 생성하지 않았습니다.

Android Studio에서 프로젝트를 만들 때 이 디렉터리를 프로젝트 위치로 지정합니다.
`settings.gradle.kts`, 루트 `build.gradle.kts`, `gradlew`, `gradlew.bat`,
`gradle/wrapper/`와 `app/`을 이 디렉터리 아래에서 관리합니다.

Gradle Wrapper는 JAR 파일을 포함해 커밋합니다. 개발자별 SDK 경로가 담긴
`local.properties`와 서명 키는 커밋하지 않습니다.

프로젝트 생성 후 필요한 JDK·Android SDK 버전과 실제 빌드·테스트 명령을 여기에 기록합니다.

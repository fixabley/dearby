# 제품·기획 — 확정 방향과 남은 범위

갱신: 2026-09-14.

## 제품 목적

새 조직·대내외 활동에 참여하고 싶은 사용자가 자격과 투자 시간 대비 얻을 경험·정보를 몰라 망설이는 진입장벽을 줄인다. 관심 직군의 경험·정보를 얻고 기존 구성원과 이어질 관계를 만드는 것이 목표다.

장기 구상은 기존 구성원과의 Q&A·대면 커피챗, 만족도에 따른 사후 크레딧 보상이다. 추천은 홍보자료를 수집·간소화해 자격과 관심사에 맞춰 하루 한 번 카드로 제공한다. 조건이 불확실하면 추가 정보 입력을 제안한다. 이 추천·수집·입력 제안·보상 정책은 아직 구현하지 않았다.

## 구현한 첫 경험

추천 카드 넘기기 → 더블탭/버튼 저장 → 조직 즐겨찾기 목록 → 관련 공고 상세. 지도와 신청/활동 기간별 캘린더 편집기 연결도 있다. 현재 데이터는 수동 검토한 번들 sample이며 실시간·개인화 추천이 아니다.

저장 대상은 회차별 공고가 아니라 지속 조직·프로그램이다. SW마에스트로 13기 카드라면 SW마에스트로를 저장한다. 조직은 부모 트리를 가질 수 있고 한 조직에 여러 연도·회차의 공고가 연결된다. 자세한 관계는 [공통 데이터](shared-data-and-source-decisions.md)를 따른다.

## 진행 방식과 이슈

기능을 구현하며 기획서를 발전시키는 애자일 방식에 합의했다. 구현 전 목적·최소 동작·완료 기준을 정하고 사용 후 동작·이유·남은 질문을 기록한다.

[#1 구조·상태 정리](https://github.com/fixabley/dearby/issues/1)는 완료했다. [#2 네이티브 UI](issue-02-native-ui.md)는 native Shared/UI·일정 위계·아이콘 표시 구현/검증을 완료했고 Draft PR7/8/9 리뷰 대기다. 미구현 제품 구상을 자동으로 현재 작업에 포함하지 않는다.

## Symposium

정본 인터뷰와 Seed는 [socrates.md](../../.symposium/scratch/socrates.md), 승인 이력은 [evolve-step.md](../../.symposium/scratch/evolve-step.md)에 있다. 최초 제품 Seed는 이력으로 보존했고 구조 개선 Seed v2의 A~F는 모두 승인됐다. 이후 FSD·Model/ViewModel/State·SwiftData/Room 및 지도·캘린더 요청을 구현했다. 같은 승인 질문을 반복하지 않는다.

스킬은 Q00/Symposium에서 설치한 Socrates·Evolve-step 등을 사용해 왔다. 새 사이클에서 사용할 스킬의 현재 SKILL.md를 읽는다. 정리 전 인터뷰·Seed 스냅샷은 [보관함](archive/2026-09-14-before-consolidation/README.md)에 있다.

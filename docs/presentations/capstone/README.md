# Dearby 캡스톤 발표 자료

이 디렉터리만 GitHub Pages에 게시합니다. 앱 소스나 환경 파일은 배포하지 않습니다.

## 내용 수정

`slides.md`가 화면의 제목·본문·표·이미지 설명·발표 노트의 원본입니다.

- 슬라이드 경계: 한 줄의 `---`
- 제목: `## 제목`
- 발표 노트와 출처: `Note:` 아래에 작성 (기본 화면에서는 숨김)
- 이미지: `![화면 아래 설명](assets/파일.png)`
- 이미지 슬라이드: 첫 줄 `<!-- .slide: class="screens" -->` 유지
- 한 장 이미지: `screens single`, 세 장 이미지: `screens triple`
- 가로형(데스크톱) 화면: `screens wide` 추가. 실제 실행 캡처는 `data-status="출처 설명"`으로 화면 하단 출처 문구를 지정합니다. 지정하지 않으면 승인 시안으로 표시합니다.
- 원본 이미지 안의 글자는 MD로 바뀌지 않습니다. 이미지를 수정한 뒤 같은 이름으로 교체하세요.
- MD에 적은 노트도 공개 배포 파일에 포함됩니다. 공개 가능한 내용만 넣으세요.

GitHub에서 `slides.md`를 수정하고 발표 브랜치에 커밋하면 배포 워크플로가 갱신합니다.

## 로컬 보기

저장소 루트에서:

```sh
python3 -m http.server 8766 --directory docs/presentations/capstone
```

http://localhost:8766 에 접속합니다. 파일을 더블클릭하는 `file://` 방식은 Markdown 로딩이 제한됩니다.

## 발표 조작

- 좌우 방향키 / Space: 슬라이드 이동
- Esc 또는 목차: 전체 슬라이드 보기
- N 또는 발표 노트: 설명과 출처 보기
- F 또는 전체 화면: 발표 화면 확대
- 화면 이미지 클릭 / Enter: 원본 확대, Esc로 닫기
- 편집 원본 다운로드: 편집 원본 저장
- `?print-pdf`를 주소 뒤에 붙이고 브라우저에서 PDF 인쇄 가능

## 내용의 범위

- 2026-10-06 기준. 최초 작성은 2026-09-29.
- 조건 편집·탐색 연결, 기본 브랜치에 통합된 주기 수집과 운영 재배포 대기 상태를 구분해 표시함.
- 웹·어드민 화면 묶음은 실제 실행 캡처: 운영 웹(https://dearby.wid.io.kr) 캡처, 저장소의 테스트용 서버 대역에 연결한 로컬 웹 캡처, 가짜 관리자 세션과 가로챈 응답으로 띄운 어드민 모의 데이터 캡처. 각 슬라이드 하단에 출처를 표시함.
- 모바일 이차원 바코드 공유·받기, 신청 확인 안내, 기기 캘린더 겹침, 웹 저장 목록의 활동별 묶음·설치 안내 화면은 진행 중으로 표시함.
- IVF·HNSW·PQ는 학습·비교 및 향후 개선안이며 현재 적용한 검색으로 소개하지 않음.
- 마지막 화면 묶음은 사용자가 지정한 `selected`의 current flow, 승인된 calendar A, 명함 관련 승인 시안 원본. 실제 실행 캡처가 아닌 디자인 시안임을 화면에 표시함.

## 구성 및 라이선스

Reveal.js 5.2.1의 배포 파일과 Markdown 플러그인을 `vendor/`에 포함했습니다. 외부 CDN 없이 실행됩니다. MIT 라이선스: `vendor/LICENSE.reveal`.
`style.css`는 배치·색상, `deck.js`는 이미지 레이아웃·노트·발표 조작만 담당합니다.

## 용어 각주 편집

발표 본문에서는 영문 약어를 풀어 씁니다. 학술 용어 뒤의 `<sup>1</sup>`은 해당 슬라이드 하단 `footnotes` 영역의 같은 번호와 연결됩니다. 각주 문구도 `slides.md`에서 수정합니다. 제품명·코드 문법·출처 주소는 정확한 원문을 유지합니다. 승인 시안 이미지 내부 글자는 원본을 유지하고 필요한 의미를 각주로 설명합니다.

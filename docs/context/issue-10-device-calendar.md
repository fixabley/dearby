# #10 기기 캘린더 완료

PR11(Android), PR12(iOS) main 병합 완료.
- `겹치는 일정 확인하기`는 환경설정에 배치, 최초 실행 설명은 켜기/나중에 1회. 명시적으로 켤 때만 권한 요청. 설정 boolean만 영속화한다.
- 개인 일정은 제목/장소 없이 바쁜 시간만 상세 세션 임시 메모리에 보유한다. OFF/종료/백그라운드/권한 철회 시 취소·정리한다.
- Primary 활동과 배색 busy 본문 블록. 교집합만 점선/경고. 활동14–16시와 busy15–17시는 `겹치는 시간 · 오후 3시부터 오후 4시까지`다. 접점은 겹침이 아니다.
- 날짜·요일 다음 줄에 작은 시간 문장. 한국 시간 중복 라벨 생략. 내부 시간대 정밀도와 export 원본 URL 메모 보존.
- iOS AX 자유 스크롤 회귀 수정: 한장 paging, 카드 내부 긴 내용 스크롤, 이전/다음 버튼. Android 기존 pager 빠른 이동 검증.

관련 테스트/빌드 통과는 각 앱 검증 문서 참조. 실제 OS/개인 일정 검증은 수행하지 않았으며 #13, 접근성 개선은 #14, iOS 오류/빈 결과 진단은 #15에서 추적한다. 과거 요구 변경·검증 이력은 archive/2026-09-15-before-pr-cleanup/issue-10-device-calendar.md에 보존했다.

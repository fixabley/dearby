## 갱신 제안

- 출처별 접근 조건을 확인한 뒤 우선 하루 1회 변경 확인을 기본 후보로 둔다. 최종 주기는 출처 조건과 실제 변경 빈도에 맞춰 정한다.
- 마지막 성공 확인 시각과 원문 링크를 기록한다.
- 명시된 모집 마감과 주최 측 모집 상태를 반영한다. 시각이 불명확하거나 상충하면 확인 필요로 남긴다.
- 일시적인 수집 실패·페이지 미응답을 활동 취소나 삭제로 판정하지 않는다. 이전 정보를 보존하고 갱신 실패를 별도 처리한다.
- 반복 수집 실패·충돌 정보는 검토 대상으로 둔다. 세부 횟수·노출 기준은 아직 미정이다.

## 중복 제안

- 같은 조직/프로그램의 같은 모집 회차가 공식 홈페이지와 SNS 등에 중복 게시되면 공고 하나로 통합하고 출처를 함께 보존한다.
- 다른 연도·기수는 별도 공고로 유지한다. 동일 회차 내 역할별 공고는 자격·일정·지원 경로를 보고 판단하며 일괄 병합하지 않는다.
- 이름이나 URL만 같다는 이유로 통합하지 않는다. 같은 URL이 다음 기수 모집으로 바뀌는 사례를 고려한다.
- 날짜·자격이 충돌하면 주최 측의 해당 회차 최신 명시 자료를 확인한다. 불명확하면 검토 상태로 두고 임의 확정하지 않는다.
- 스크랩 대상 조직/프로그램은 공고의 갱신·마감과 별개로 유지한다.

2026-09-22까지의 후속 승인으로 마감된 모집도 탐색에 포함하고 프로그램 카드·상세의 회차별 공고로 제공한다. 선택 직무 기준 모집 중 프로그램을 우선하며 고유 프로그램 수를 집계한다. 현재 추천·필터에는 이번 회차 제공 근거가 있는 경험만 반영하고 과거 경험은 상세에서 구분한다. [재기획 정본](replanning-2026-09.md)의 승인 절을 따른다. 최초 출처 채택·갱신 주기·중복 처리의 세부 정책과 모집 없는 프로그램의 과거 경험 검색 방식은 미정이다.

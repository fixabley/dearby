# 실제 공식 안내의 태그 검토 예시

확인: 2026-09-21 KST. 웹 도구로 아래 공식 페이지를 열람했다. 모델의 수동 분류 제안이며 사용자가 개별 프로그램 태그를 승인하거나 실제 앱 데이터에 등록한 것은 아니다. 수집기·분류기·추천 기능을 실행한 결과가 아니다.

## 확인 출처

- [YAPP 모집 안내](https://www.yapp.co.kr/recruit): 역할·지원 조건·일정·프로그램 FAQ. FAQ 링크 문구에 28기를 언급하나, 화면의 월일만으로 모집 연도나 현재 접수 여부를 확정하지 않는다.
- [디프만 소개](https://www.depromeet.com/): 팀 협업과 서비스 출시 경험의 프로그램 소개, 18기 세션 설명과 19기 모집 알림이 함께 존재한다.
- [디프만 모집 안내](https://www.depromeet.com/recruit): 18기 모집 기간을 2026-02-12~02-18로 명시하며 회차별 세션 일정을 제공한다. 이 회차는 확인일 기준 모집 종료다. 19기의 조건/일정은 여기서 추정하지 않는다.

서비스 제작이 있다고 창업까지 제공한다고 추론하지 않는다. 창업을 뒷받침하는 직접 활동 근거가 없으면 창업 방향 태그를 부여하지 않는다.

## 이번 사례에서 발견한 명세 보완점

다음은 2026-09-21 원문 대조로 도출한 제안이다. 1번 구분과 2번 현재/과거 회차 원칙은 2026-09-22 후속 승인됐다. 3번 용어는 행위/속성 구조로 재검토하며 4번의 모든 후보 생성 정책은 미정이다. 개별 사례 태그의 운영 승인을 뜻하지 않는다.

1. 태그 근거는 요구/우대 자격과 실제 제공 활동을 구분한다.
2. 프로그램 일반 소개와 회차별 일정을 구분하고, 지난 회차 경험을 다음 회차에 자동 복제하지 않는다.
3. ‘또래네트워킹’이 나이 비슷한 사람만 의미하는지, 같은 관심의 동료까지 의미하는지 명확히 한다. YAPP에는 대학생 이외의 참여자도 존재하여 동년배를 보장할 수 없다.
4. 모호한 문구의 후보는 내부 검토 대기이고, 정보가 전혀 없는 모든 태그를 무조건 검토 대상으로 생성하지 않는다.

기존 승인 계약인 불확실 후보 비노출·승인 후 반영을 적용한 예시일 뿐, 자동화 정확도나 운영 처리량을 검증한 것은 아니다.

청강은 설명·강연을 듣는 활동이라는 근거가 있을 때 후보를 부여한다. 실제 기존 사례에는 명확한 청강/과제수행 근거를 이번 보존 자료만으로 확보하지 못했으므로 해당 예시를 만들어 사실처럼 추가하지 않는다.

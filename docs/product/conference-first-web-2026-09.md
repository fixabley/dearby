# 컨퍼런스 우선 웹 — 2026-09-24 결정

## 사용자 승인

기존 네이티브/API 실행 코드는 보존 후 웹으로 재구현한다. 최근 재기획의 프로그램 탐색·필터·상세·조직/프로그램 스크랩을 구현하며, 첫 콘텐츠는 IT 컨퍼런스로 좁힌다. 고등학생·대학생·취준생도 대상이다. 사용자가 잠든 동안 범위 안의 미정 사항은 담당자가 판단하여 진행하도록 승인했다.

YouTube의 검색·메뉴·주제 칩·썸네일 그리드처럼 빠르게 훑을 수 있는 구조를 사용한다. 영상 서비스가 아니므로 가짜 재생·조회수·구독은 넣지 않는다. shadcn/ui는 선택 사항이며 설치 그 자체가 목표가 아니다.

## 콘텐츠와 탐색

- 프로그램을 탐색 단위로 삼고 상세에서 회차별 참가 공고를 본다. 조직과 프로그램은 별도로 저장한다.
- 최신 확인 회차가 과거 행사일 수도 있다. 날짜가 지났거나 등록이 마감되어도 제외하지 않고 명확히 표시한다. 선택 주제에 맞는 현재 대표 공고 안에서 조건을 평가하며 서로 다른 공고의 조건을 합치지 않는다.
- 등록 중 → 등록 예정 → 상태 미확인 → 등록 마감 → 과거 행사 순서를 첫 구현의 정렬로 선택했다. 과거 회차는 최근 날짜를 우선한다. 이는 추천 학습을 구현한 것이 아니다.
- 가격·자격·장소·등록 일정을 확인하지 못하면 미확인으로 표시한다. 프로그램에 대한 관심과 실제 참가 자격을 구분하며 자격만으로 탐색에서 제거하지 않는다.
- 결과가 없으면 선택 조건 일부를 유지하는 유효한 조합과 결과 수를 제안한다. 현재 전체 목록을 함께 볼 수 있다.
- 검색에 프로그램명뿐 아니라 주최 조직명을 포함한다. 직무·기술 주제와 실제 제공 경험을 구분한다. 연사의 발표를 일반 참가자의 발표 경험으로 태깅하지 않는다.

## 카드와 상세

공식 OG/공유 이미지·포스터 → 적절한 공식 랜딩페이지 캡처 → 기본 이미지 순서로 썸네일을 준비한다. 종류·원문·확인일은 기록한다. YouTube 영상은 향후 회차 미리보기 보조 자료로 활용할 수 있지만 필수는 아니다.

카드는 행사명/회차·주최·등록 상태·개최일·장소·비용·주제를 텍스트로 읽을 수 있어야 한다. 상세는 모바일에서도 참가 정보가 긴 부연 설명보다 먼저 나온다. 신청은 공식 사이트로 연결하며 Dearby가 신청 접수나 결제를 대행하지 않는다.

## 구현 범위와 운영 한계

이번 데이터는 공식 출처를 수동 확인한 2026-09-24 스냅샷이다. 실시간 크롤러·API·계정·기기간 저장 동기화·개인 자격 자동 판정·일일 개인화 추천은 구현 범위 밖이다. 브라우저 저장 실패를 알려주고 기존 값을 보존하며, 새로고침·여러 탭·초기 hydration 이후 저장 상태를 일관되게 표시한다.

우아한테크코스 등 교육 프로그램은 후속 확장으로 둔다. 초기 컨퍼런스 목록은 광범위 조사 목록의 일부이며 미수록을 미존재로 해석하지 않는다. [조사 목록과 수록 기준](../research/korea-it-conferences-2026-09.md)을 함께 관리한다.

# 컨펌된 네이티브 화면 구현 기준

## 2026-10-03~04 적용 범위

최신 사용자 승인으로 모든 승인 화면을 **예시 데이터와 화면 이동만 있는 모바일 프로토타입**에 적용한다.
명함·프로필·QR·명함함도 포함하며 실제 인증·서버 호출·영구 저장·카메라·기기 캘린더는 연결하지 않는다.
아래 과거 설명의 실제 서비스 성공·권한·테스트 전용 fixture 요구보다 이번 승인이 우선한다.
현재 시안 대응과 공통 컴포넌트 경계는 [모바일 프로토타입 적용표](mobile-prototype-reference-map.md)를 따른다.
캘린더는 이번 사용자가 다시 직접 지정한 [A안](approved/calendar-overlap-a.png)을 사용한다.
사진은 승인 시안에서 재구성한 생성 예시 자산을 사용하며 공식 행사 사진으로 표시하지 않는다.

## 기존 시각 기준

2026-09-27 사용자: “화면이 아까 렌더링한 화면이랑 많이 다른것같아”, “수정을 거쳐서 컨펌된 화면들을 참고자료로 활용해줘”. 새 디자인을 제안하는 작업이 아니라 합의된 화면을 실제 앱에 재현하는 작업이다.

## 근거와 우선순위

- [원본 목록](approved/manifest.json)은 대화에서 생성한 PNG를 변경 없이 복사한 것이다. 생성 순서만으로 승인됐다고 단정하지 않는다. 아래에는 화면별 수정 흐름과 마지막 사용자 지시를 함께 기록한다.
- 마지막 명시적 사용자 수정 > 해당 흐름의 수정 후 시안 > 기존 개발 기본 스타일 순서다. 초기 시안·반려된 시안은 구현 기준에 포함하지 않는다.
- 이미지는 시각 기준이며 샘플 이름·일시·연락처·공고는 제품 데이터가 아니다. 상태·인증·서버 공개 범위·기기 저장 계약을 유지한다.
- 기기 프레임·이미지의 종이 질감·생성 노이즈·잘못 그려진 글자는 앱에 재현하지 않는다. 실제 기기 화면 영역을 비교한다.

저장 탭·인증·오류 등 별도 최종 시안이 없는 상태는 위 기준의 색·간격·버튼을 재사용한다. 새로운 컨펌 시안이 있다고 주장하지 않는다. 상세/홈의 초기 4탭 시안은 이후 확정한 발견·저장·QR·받은 명함·내 프로필 5탭으로 조합한다.

## 공통 표현

- 흰색 배경, 청록 강조, 회색 보조 정보, 옅은 민트 명함, 얇은 구분선. 아이보리·플랫폼 임의 동적 팔레트 금지.
- [확정 로고](approved/logo-teal.png)를 사용한다. 일반 글꼴로 dearby를 입력하는 것으로 대체하지 않는다. [흰 로고](approved/logo-white.png)는 어두운 배경용 원본이다.
- 시안의 화면 영역을 기준으로 좌우 여백 약 20pt/dp, 보통 요소 간격 8/12/16/24, 주 CTA 높이 48~52 이상, 모서리 약 10~12를 초기 구현값으로 사용하고 캡처 비교로 조정한다. 이 수치는 추정 구현값이지 사용자가 지정한 정밀 토큰은 아니다.
- 작은 글자 계층도 Dynamic Type/fontScale에 반응한다. 아이콘이 작더라도 iOS 44pt/Android 48dp 이상의 히트 영역. 잘림·겹침은 스크롤/유연한 높이로 해결한다.
- 네이티브 접근성·시스템 시트·뒤로가기 동작을 보존하되 SwiftUI 기본 List의 그룹 배경, 과도한 대제목, Material 기본 pill 버튼으로 시안의 레이아웃을 바꾸지 않는다.
- 기능별로 실제 재사용되는 카드/타임라인/버튼만 공유한다. 새 테마 엔진·네비게이션 엔진·이미지 렌더링 화면을 만들지 않는다.

## 검증 완료 조건

1. 변경 전에 이번 실행의 실제 앱 화면을 캡처한다. 과거 증거는 참고로만 둔다.
2. 원본 시안과 실제 화면을 동일 흐름/비슷한 뷰포트로 나란히 열어 비교한다. fixture는 테스트 타깃 전용임을 표시한다.
3. 수정 후 발견·상세·내 프로필·QR·받은 명함·내 명함 선택 캡처를 남긴다. 원본/전/후와 남은 차이를 플랫폼 보고서에 연결한다.
4. 관련 기존 기능 회귀·lint/구조·빌드를 실행한다. 시각 수정 자체를 그대로 복제한 단위 테스트를 추가하지 않는다.
5. 큰 글자·작은 화면의 접근성 검증과 일반 글자 시안 일치 검증을 구분한다. 실행하지 않은 항목과 미구현 기능은 그대로 명시한다.

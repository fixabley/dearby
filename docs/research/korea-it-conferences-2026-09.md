# 국내 IT 컨퍼런스 조사와 Dearby 수록 기준

조사일: **2026-09-24 KST**. 국내 기업·조직의 개발/IT 행사, 국내 커뮤니티 행사, 글로벌 기업의 한국 행사를 조사했다. 아래는 **공식 출처에서 확인한 회차**이며 모든 행사의 최신 회차나 국내 전체 행사의 완전한 목록을 보장하지 않는다. 검색에서 2026년 공지가 나오지 않았다는 이유로 폐지·휴식을 단정하지 않는다.

## 제품에 반영한 결정

- 첫 버전은 컨퍼런스 탐색에 집중한다. 교육 과정인 우아한테크코스, 채용, 부트캠프, 단독 워크숍은 별도 확장 후보다.
- 프로그램 카드 → 회차별 상세 구조, 조직/프로그램 별도 스크랩을 유지한다. 회사가 발표자·후원사라는 이유만으로 주최 조직으로 분류하지 않는다.
- 공개 참가·선발 참가·온라인 시청·내부 행사·과거 기록을 구분한다. 신청 버튼이 남아 있다는 사실만으로 모집 중으로 판단하지 않는다.
- 날짜가 지난 공지는 과거 회차로 표시한다. 개최 예정 공지만 있는 경우 실제 개최 완료를 단정하지 않는다. 가격·대상·장소·접수 기간을 확인하지 못하면 미확인으로 남긴다.
- 썸네일은 공식 OG/공유 이미지·포스터를 우선하고, 적합한 이미지가 없으면 실제 랜딩페이지 캡처, 그다음 기본 이미지 순서로 사용한다. 이미지 출처와 확인일을 기록한다. 외부 공개 배포 전 이미지별 재사용 조건을 검토해야 한다.
- 대상을 대학생으로 한정하지 않는다. 고등학생·대학생·취준생도 탐색할 수 있으며 행사 자격 조건은 행사별로 안내한다. 자격 미충족만으로 자동 제외하지 않는다.
- 아래 조사 목록과 웹의 게시 데이터는 다르다. 초기 웹에는 정보와 이미지가 준비된 행사부터 수록한다. 이 조사는 실시간 크롤러나 자동 갱신의 구현을 뜻하지 않는다.

- **CODEGATE 2026**: 대학의 참가 지원 공지는 발견했으나 대학 지원 대상·지원 마감을 행사 전체 자격·마감으로 옮기면 안 된다. Junior CTF 연령 제한 역시 일반 컨퍼런스의 제한이 아니다. [행사](https://codegate.org/), [Junior](https://jr.codegate.org/).
- **POC 2026**: 공식 Training 등록 페이지는 확인했지만 교육비에 컨퍼런스가 포함되지 않는 안내가 있다. 교육과 컨퍼런스 회차 정보를 분리해야 한다. [교육 등록](https://event.pocsec.com/event/POC2026-Training).
- **AI DevCon 2026**: 공식 사이트는 확인했으나 수집 가능한 내용이 부족해 주최·일시·자격 검증 대기. [공식](https://www.ai-devcon.kr/).
- **무신사 패턴 26**: 언론 보도 발견, 공식 개최·참가 원문 확보 후 게시.
- **BOAZ / PseudoCon / Rust Korea / React Seoul / Devoxx Korea**: 명칭·과거 행사 단서만으로 현행 회차를 생성하지 않는다. 신규 회차의 주최자 원문 확인 대기.
- **쿠팡·쏘카·카카오페이·카카오뱅크 자체 연례 행사**: 타 행사 발표 참여와 자체 주최를 구분해야 하며 이번 조사에서 독립 현행 회차를 확정하지 못했다.
- **GDG Incheon Road to DevFest**, **GDG Campus 코딩 모임**, **Build with Gemini All Builders Day**: 밋업·코딩 모임·워크숍으로 구분하고 컨퍼런스와 무조건 합치지 않는다. [Google 워크숍](https://cloud.google.com/events/intl/ko-kr/build-with-gemini-seoul/all-builders-day?hl=ko).
- **BIXPO**: 에너지 산업 전시·컨퍼런스. IT 개발 탐색의 첫 범위에서는 후순위. [공식](https://bixpo.kr/main.php).
- **HDCON**: 종료된 과거 사업, 현재 모집 행사로 표시하지 않는다. [KISA 종료 안내](https://www.kisa.or.kr/401/form?postSeq=2451).
- **우아한테크코스**: 컨퍼런스가 아닌 교육 과정. 향후 프로그램 유형 확장 시 반영. [공식](https://www.woowacourse.io/).

## 갱신·확장 방법

1. 조직의 공식 행사 목록·기술 블로그·공식 커뮤니티 챕터를 출처로 등록한다.
2. 프로그램 고유 ID와 회차 ID를 분리한다. 공동 개최·이름 변경·통합은 중복을 검토한다.
3. 회차마다 출처 URL, 확인일, 일시, 장소/온라인 방식, 참가 대상, 가격, 신청 기간·선발 방식, 주제, 이미지 원본을 기록한다.
4. 필드별로 확인된 정보만 게시한다. CFP·후원·학생 지원·교육·참가 등록 공고를 서로 구분한다.
5. 고정 스냅샷 이후의 취소·매진·장소 변경은 자동 반영되지 않는다고 안내하고 원문을 쉽게 열게 한다. 갱신 주기는 후속 운영 정책으로 정한다.

이 문서에는 핵심·인접 공식 행사/프로그램 **58개 행**이 있으며, 중복 계보(DEVIEW/DAN, SLASH/TMC), 지역 회차, 공동 개최가 포함되어 고유 컨퍼런스 개수와 같지 않다. 별도 대기 후보는 게시 검증을 통과한 데이터가 아니다.
